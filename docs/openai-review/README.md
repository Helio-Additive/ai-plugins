## ChatGPT discovery incident

The reported installation links the GitHub marketplace. It reads the committed native bundles. Release ZIP selection cannot explain why tools appear in Code but not reliably in Chat, Work or Web. In an isolated local ChatGPT desktop parser test, native and compatibility layouts both exposed the Slicing server with six skills. A portable-only directory exposed six skills and zero servers in that desktop parser. This does not test the directory importer or reproduce hosted ChatGPT behaviour. The local callback fixture also observed the public client with the expected loopback callback and zero dynamic registrations. The public scanner status is **unknown**.

OpenAI Support has acknowledged comparable reports and asks for a scan or Inspector result, endpoint, UTC timestamp and screenshots when escalating. For Helio, capture the same read-only prompt, plugin version, tool list and account scope in working Code and failing Chat/Work/Web, then compare with the saved public scan. The reports support investigating this separately; they do not identify the Helio root cause.
