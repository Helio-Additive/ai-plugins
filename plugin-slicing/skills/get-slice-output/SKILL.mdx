---
name: get-helio-slice-output
description: Retrieve a download URL for a completed Helio Additive slicing job when a user asks for its output.
---

Use this skill when the user explicitly asks to download, share, or obtain the output from a completed slicing job.

1. Use `get_slice` first unless the current conversation already contains a fresh completed result for the requested slice.
2. If the slice is not complete, report its current state and do not request a URL.
3. Inspect the `get_presigned_url` schema and call it with only the required identifier or output reference.
4. Return the URL exactly as provided, together with any expiry or usage instruction returned by the service.
5. Treat the URL as time-limited access. Do not expose it to anyone other than the user or persist it in a repository, document, or external service.
